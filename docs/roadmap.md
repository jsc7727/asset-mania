# Roadmap

1. **v0.1 — Inspect and plan:** deterministic, offline inspection with portable manifests and
   reports.
2. **v0.2 — 3D-guided image:** Blender render-pass planning and a BYOK GPT Image provider behind
   explicit upload and cost approval.
3. **v0.3 — Generic image to 3D:** provider adapters for local engines whose *entire*
   dependency closure has been independently cleared. See the licensing correction in
   [research](research.md): a permissive top-level license is not sufficient.
4. **v0.4 — Face/head:** a separately gated workflow with rights confirmation, provenance, and
   conservative likeness claims.
5. **Later — Asset Mania Cloud:** an execution and collaboration option that shares the open
   project format rather than locking users into a separate contract.

The current repository implements the v0.1 inspection and planning foundation. See
[Getting started](getting-started.md) for the working command and current capability limits.
