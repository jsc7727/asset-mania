# Asset Mania rules

These short, operational rules are the source of truth for repository work. Start at
[the index](index.md), search the relevant topic before implementation, and keep detailed
guidance here rather than expanding [AGENTS.md](../AGENTS.md).

Rules complement the approved [design specification](../docs/superpowers/specs/2026-08-19-asset-mania-open-source-skill-design.md).
If they conflict, stop and resolve the conflict against that specification before changing the
public contract.
