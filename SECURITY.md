# Security Policy

## Supported versions

Until the first public release, only the default branch is supported and the project remains
pre-alpha.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability, privacy exposure, credential
leak, or unsafe data-handling behavior. Contact the repository administrator privately through
the GitHub account for `jsc7727/asset-mania`, including a minimal reproduction, impact, and any
safe mitigation. Do not attach private source assets, credentials, or real-person images.

We will acknowledge receipt, assess the report, coordinate a fix where appropriate, and request
permission before publishing details.
