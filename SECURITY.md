# Security Policy

## Supported versions

Until the first public release, only the default branch is supported and the project remains
pre-alpha.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability, privacy exposure, credential
leak, or unsafe data-handling behavior. Submit the report through
[GitHub private vulnerability reporting](https://github.com/jsc7727/asset-mania/security/advisories/new),
including a minimal reproduction, impact, and any safe mitigation. Do not attach private source
assets, credentials, or real-person images.

The repository administrator enables private vulnerability reporting when the public repository
is created. If the private form is not available, do not disclose the issue in a public issue;
wait for the private reporting route to be enabled.

We will acknowledge receipt, assess the report, coordinate a fix where appropriate, and request
permission before publishing details.
